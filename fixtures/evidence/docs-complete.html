Quayside timetable API (test only)

Quayside Ferries publishes its timetable through a small read-only service. TEST / DEMONSTRATION ONLY - NOT A REAL SERVICE.

Every request carries an API key in the X-Api-Key header, issued from the operator dashboard.

When a key is revoked the next request made with it is answered 401 and the client must ask for a new key.

The timetable covers three ferry routes and is refreshed every five minutes.
